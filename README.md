# JomLepakz

JomLepakz helps Universiti Malaya (UM) students find people to do activities with through the core loop: **Post -> Discover -> Join -> Meet**.

## Current development status

Planning and visual reference stage. The repository contains the V1 scope, development checklist, and Base44 screenshot handover. The application has not been scaffolded; there is no `package.json` yet. The planned initial beta is for 10-20 UM students.

## Main stack

Planned: Next.js and React, with Node.js and npm for development. Dependencies and versions have not been configured. Backend, database, and authentication choices remain to be confirmed.
